Q – Calculator Using UDF and Switch

This calculator program performs addition, subtraction, multiplication, division, and modulus using User Defined Functions (UDF) and a switch statement. Separate functions such as add(), sub(), mul(), divi(), and mod() perform each calculation. The program uses a loop so the calculator continues to run until the user chooses 0 for exit. The switch statement checks the user’s choice and calls the appropriate function. For example, if the user selects 1, the addition function is called; if the user selects 2, subtraction is performed.
